# Project Structure

## Root
- `xxread-ios/`: Native iOS project root.
    - `xxread/xxread/`: Source code directory.
        - `App/`: App entry point (`xxreadApp.swift`).
        - `Core/`: Core services.
        - `Features/`: Feature modules.
        - `Common/`: Shared components.
        - `Resources/`: Assets.
- `lib/`: Existing Flutter source code.
- `iOS_PROJECT_PLAN.md`: iOS migration plan.
