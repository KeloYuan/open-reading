## 截图拍摄建议

### 移动端截图

1. **使用真机或模拟器**：推荐使用真实设备截图
2. **隐藏状态栏敏感信息**：可以在开发者选项中启用"演示模式"
3. **保持屏幕整洁**：截图前清理通知栏
4. **统一设备**：建议所有截图使用同一设备，保持一致性

### 桌面端截图

1. **调整窗口大小**：保持1920×1080或16:9比例
2. **关闭无关窗口**：只保留应用窗口
3. **使用内置截图工具**：
   - Windows: Win + Shift + S
   - macOS: Cmd + Shift + 4
   - Linux: 使用Screenshot工具

### 内容建议

1. **使用示例数据**：
   - 添加3-5本示例书籍
   - 创建一些示例笔记和高亮
   - 生成一定的阅读统计数据

2. **展示关键功能**：
   - 确保功能点清晰可见
   - 避免空白或加载中的页面
   - 突出显示正在演示的功能

3. **注意隐私**：
   - 不要包含真实的个人信息
   - 使用示例用户名和数据

## 截图后处理

1. **检查质量**：确保图片清晰，无模糊
2. **统一尺寸**：同平台的截图保持相同尺寸
3. **压缩大小**：在不影响质量的前提下适当压缩（建议单张<500KB）
4. **重命名文件**：严格按照清单中的文件名命名

## 替换步骤

1. 将所有截图按照上述文件名保存到 `screenshots/` 目录
2. 确保文件名完全匹配（区分大小写）
3. 使用Markdown编辑器预览，检查图片是否正确显示
4. 准备好后转换为PDF格式

## PDF转换建议

可以使用以下工具将Markdown转换为PDF：

1. **Typora**（推荐）
   - 打开MD文件
   - 文件 → 导出 → PDF
   - 保持默认设置即可

2. **Pandoc + LaTeX**
   ```bash
   pandoc 软著-用户使用手册.md -o 软著-用户使用手册.pdf --pdf-engine=xelatex -V mainfont="SimSun"
   ```

3. **在线工具**
   - Markdown to PDF (https://www.markdowntopdf.com/)
   - CloudConvert (https://cloudconvert.com/)

4. **VS Code + 插件**
   - 安装 "Markdown PDF" 插件
   - 右键 → Markdown PDF: Export (pdf)
